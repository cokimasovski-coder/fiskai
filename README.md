# FiskAI

Лична апликација за трошоци и скен на фискални сметки.

## Инсталација на телефон

1. Вклучи GitHub Pages: repo Settings → Pages → Branch `main` → `/` → Save
2. Отвори: https://cokimasovski-coder.github.io/fiskai/
3. Android Chrome: мени → Add to Home screen / Инсталирај апликација
4. iPhone Safari: Share → Add to Home Screen

После секоја нова верзија што ја пуштаме на GitHub, отвори ја апликацијата и повлечи надолу за refresh.
